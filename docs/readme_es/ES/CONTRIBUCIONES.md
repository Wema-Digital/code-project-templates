# Contribuciones

## Problemas (Issues)

Los problemas son muy valiosos para este proyecto.

  - Las ideas son una fuente valiosa de contribuciones que otros pueden realizar.
  - Los problemas muestran dónde este proyecto tiene deficiencias.
  - Al hacer una pregunta, señalas dónde los colaboradores pueden mejorar la experiencia del usuario.

Gracias por crearlos.

## Solicitudes de Extracción (Pull Requests)

Las solicitudes de extracción son una excelente manera de incorporar tus ideas en este repositorio.

Al decidir si fusionar una solicitud de extracción, evalúo los siguientes aspectos:

### ¿Expresa claramente su intención?

Debes ser claro sobre el problema que intentas resolver con tu contribución.

Por ejemplo:

> Agregar enlace al código de conducta en README.md

No proporciona información sobre la razón de este cambio.

> Agregar enlace al código de conducta en README.md porque los usuarios no siempre revisan CONTRIBUCIONES.md

Este mensaje indica el problema que encontraste y la acción que tomaste para solucionarlo.

### ¿Es de buena calidad?

  - No contiene errores ortográficos.
  - Tiene una lectura clara y comprensible.
  - Para contribuciones en inglés: Obtiene una buena puntuación en
    [Grammarly](https://www.grammarly.com) o [Hemingway App](https://www.hemingwayapp.com/).

### ¿Acerca este repositorio a su visión?

El objetivo de este repositorio es:

  - Proporcionar un README.md y documentos asociados que cualquiera pueda copiar y pegar en su proyecto.
  - Que el contenido sea utilizable por alguien que no haya escrito algo similar antes.
  - Fomentar una cultura de respeto y gratitud en la comunidad de código abierto.

### ¿Cumple con el Contributor Covenant?

Este repositorio tiene un [código de conducta](CODIGO_DE_CONDUCTA.md). Eliminaré cualquier contenido que no lo respete.
